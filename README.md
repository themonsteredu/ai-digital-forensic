# 디지털 포렌식 수사관 — CASE 017

중학생이 실제 수업용 공폰과 microSD를 조사하고, 웹 포렌식 분석 시스템에서 증거를 교차검증해 사건을 재구성하는 온·오프라인 결합형 직업체험 웹앱입니다.

## 실행 화면

- 학생 수사 시스템: `/`
- 교사용 관리센터: `/teacher`
- Vercel 배포본: https://ai-digital-forensic.vercel.app/

교사용 접근 코드는 `3035`입니다. 초기화처럼 중요한 작업은 같은 코드를 다시 확인합니다. 이 코드는 학생·교사 화면을 수업 중 분리하기 위한 장치이며 실제 인증 보안 경계가 아닙니다.

## 핵심 경험

1. 보안 시스템 접속과 CASE 017 사건 브리핑
2. 실제로 움직이는 CCTV 관찰
3. 증거물 E-01 인계와 수업용 PIN 퍼즐
4. 실제 공폰의 기본 갤러리·파일 앱·외부 저장매체 조사
5. microSD 삭제 파일 실제 복구 및 증거 코드 등록
6. 사진 메타데이터·위치 기록·CCTV 프레임 교차검증
7. 드래그 가능한 타임라인과 수사실형 증거 보드 구성
8. 근거 3개 이상을 포함한 최종 수사보고서 제출
9. 제출 증거 기반 사건 재구성 엔딩
10. 디지털 포렌식 업무·진로·수사 윤리 연결

교사용 관리센터에는 21단계 학생 화면 미리보기, 40·50·60·90분형 자동 시간 배분, 전체 수업지도안, 15장 내장 발표 슬라이드, 5개 모둠 진행 현황, 단계형 힌트, 공폰 구매·초기화·실제 데이터 복사·microSD 복구 테스트·출력물·10분 점검을 묶은 수업 준비센터, 3035 재인증 CASE RESET 기능이 포함되어 있습니다.

## 수업용 사건 코드

- 공폰 PIN 퍼즐 정답: `1017`
- 삭제 흔적 등록 코드: `DF-2048`
- 결정적 복구 파일: `IMG_2048.jpg`

이 값들은 모두 CASE 017 가상 수업 데이터용입니다. 실제 기기 보안 우회나 실제 개인정보 조사를 다루지 않습니다.

## 로컬 실행

필수 환경은 Node.js 22.13 이상입니다.

```bash
npm ci
npm run dev
```

검증 명령:

```bash
npm run lint
npm run build
```

## 수업 전 준비

- 기존 계정과 개인정보를 제거한 수업 전용 공폰만 사용합니다.
- 공폰에는 CASE 017 가상 축제 사진과 일반 문서 파일만 실제 파일로 넣습니다.
- 메시지·통화기록은 공폰 앱이 아니라 웹 포렌식 시스템의 `MOBILE EXTRACTION` 결과로 제공합니다.
- 가짜 문자·전화·메모·홈 화면, APK 사건팩, 별도 companion app은 개발하거나 설치하지 않습니다.
- microSD에는 `IMG_2039.jpg`, `IMG_2040.jpg`, `IMG_2041.jpg`, `IMG_2042.jpg`, `IMG_2048.jpg`를 넣고 `IMG_2048.jpg`만 삭제한 뒤 새 데이터를 쓰지 않습니다.
- 복구 결과는 microSD가 아닌 노트북의 별도 폴더에 저장합니다.
- 학교가 승인한 복구 도구와 USB 카드 리더기를 수업 전에 점검합니다.

## 교육 원칙

- 삭제했다고 항상 복구되는 것은 아닙니다.
- 복구된 데이터가 곧바로 범죄 증거가 되는 것은 아닙니다.
- 서로 독립된 디지털 증거의 시간과 내용을 교차검증해야 합니다.
- 증거 원본, 무결성, 개인정보 범위, 취급 기록을 우선합니다.

## 디자인·에셋

한글 UI는 로컬 S-Core Dream 4·5·6·7 굵기를 사용합니다. 폰트 고지 내용은 `public/fonts/LICENSE.txt`에서 확인할 수 있습니다. CCTV 배경, 인물 레이어, 공폰 갤러리 사진과 삭제 복구 사진은 이 교육용 가상 사건을 위해 제작된 이미지입니다.

교사용 다운로드 자산을 다시 만들 때는 다음 명령을 사용합니다.

```bash
python3 scripts/generate-case017-assets.py
```
